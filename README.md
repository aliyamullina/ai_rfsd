# Анализ финансовых данных организаций

## Описание проекта

В работе проведён анализ финансовых данных организаций из датасета [RFSD](https://github.com/irlcode/RFSD).

Для анализа использовались **Pandas, NumPy, Matplotlib и Seaborn**. Перед проведением анализа количество данных было сокращено до **1000 строк и 20 колонок**.

## План работы
1. Ограничение выборки данных
1. Описательная статистика
1. Гистограммы и выбросы
1. Матрица корреляции
1. Диаграмма рассеивания

## Основные результаты
В данных выявлены сильная асимметрия финансовых показателей, выбросы и высокая корреляция между рядом показателей. Также обнаружены организации с отрицательным капиталом и убытками.
